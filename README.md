# 🍅 Pomodoro Web

Una aplicación web simple y minimalista basada en la Técnica Pomodoro, diseñada para ayudar a mantener la concentración durante sesiones de estudio, trabajo o desarrollo de proyectos.

## ✨ Características

* Temporizador Pomodoro configurable.
* Ciclos automáticos de trabajo y descanso.
* Interfaz limpia y fácil de usar.
* Indicador visual del tiempo restante.
* Diseño responsive para escritorio y dispositivos móviles.
* Sin dependencias innecesarias.

# 🚀 Objetivo del proyecto

Este proyecto fue desarrollado como una práctica de desarrollo web enfocada en la creación de interfaces interactivas utilizando tecnologías web modernas.

La aplicación busca ofrecer una experiencia simple y libre de distracciones, permitiendo al usuario concentrarse en una tarea durante períodos definidos de tiempo.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS
* JavaScript (Vanilla JS)

## 🍅 ¿Qué es la Técnica Pomodoro?

La Técnica Pomodoro es un método de gestión del tiempo desarrollado por Francesco Cirillo en la década de 1980.

Consiste en:

1. Elegir una tarea.
2. Trabajar durante cierta cantidad de minutos.
3. Tomar un descanso corto de minutos.
4. Repetir el ciclo.
5. Después de cuatro sesiones, tomar un descanso más largo.

El objetivo es mejorar la concentración y evitar la fatiga mental.

## 📜 Desarrollo

Esta aplicación nació como una herramienta personal para organizar mejor mis sesiones de estudio y trabajo. Buscando una forma simple de mantener la concentración y evitar el desorden en mis tareas diarias, decidí desarrollar mi propia versión de un temporizador Pomodoro utilizando HTML, CSS y JavaScript.

Además, incorporé un sistema de sonidos aleatorios al finalizar cada sesión, agregando un elemento de sorpresa que ayuda a romper la monotonía y hace más entretenida la experiencia de uso.
